Configuration dataclasses for the whole study. `MultiTSOConfig` is the single object every runner takes; `CascadeConfig` is the per-controller slice handed to a DSO. These types are the provenance record: each run serialises its config to `config.json`, and the analysis admission filters read that block to decide whether two runs are comparable.
